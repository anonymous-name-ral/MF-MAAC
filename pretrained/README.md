Pretrained models: because of their size, the trained checkpoints will be provided through Google Drive. To keep the
review double-anonymous, the link will be added to the main README after the paper is accepted.
Place the downloaded files here, so that the checkpoints are at `pretrained/rware/<model>.pt` and
`pretrained/uav_lds/<model>.pt`; `python evaluate.py --model all` (in `rware/` or `uav_lds/`) then evaluates them.
